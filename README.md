# CV Analyzer Frontend

A modern and responsive frontend application for analyzing resumes and CVs. Users can upload their resumes, view analysis history, and receive insights such as ATS score, skill analysis, missing keywords, and improvement suggestions.

## Features

- Upload Resume UI
- Resume Analysis Dashboard
- ATS Score Preview
- Analysis History Section
- Modern Responsive Design
- Sidebar Navigation
- Interactive UI Components
- React-Based Architecture

## Tech Stack

- React.js
- CSS3
- JavaScript (ES6)
- React Router DOM
- React Icons / Lucide Icons

## Screens

- Resume Upload Page
- Analysis History Page
- Sidebar Navigation
- Dashboard Layout

## Future Improvements

- Backend Integration
- Real Resume Parsing
- AI-Based Suggestions
- Authentication System
- PDF Report Export
- Cloud Storage Support
